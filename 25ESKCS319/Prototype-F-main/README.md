🤖 Prototype-X

Prototype-X is a smart AI chatbot that I designed and built to create natural, human-like conversations with a strong focus on Hinglish and Indian English. The goal of this project is not just to answer queries, but to simulate a real conversational experience with speed, context awareness, and personality.

I developed the backend using Groq APIs for ultra-fast responses and structured the system to support memory, context linking, and future scalability. This project reflects my vision of building a next-generation AI assistant that evolves with the user and delivers meaningful interactions.

🚀 Features
	•	AI-powered chatbot (Hinglish + English support)
	•	Fast responses using Groq API
	•	Clean and responsive UI
	•	Context-ready architecture (memory support)
	•	Easily deployable (Replit / Render / Railway)

🛠️ Tech Stack
	•	Python (Flask)
	•	JavaScript (Frontend)
	•	Groq API (LLM)
	•	HTML / CSS

⚙️ Installation

1. Clone the repository
2.git clone https://github.com/your-username/Prototype-X.git
cd Prototype-X

2. Install dependencies
3. pip install -r requirements.txt

3. Setup environment variables
Create a .env file and add:

GROQ_MAIN_KEY=your_api_key
GROQ_MODEL=llama-3.3-70b-versatile
PORT=5000

⚠️ Do not upload .env to GitHub

▶️ Run Locally

python server.py

Then open in browser:
http://localhost:5000


🌐 Deployment

This project can be deployed on:
	•	Replit (recommended for beginners)

	•	Railway (for better performance)
