# Student Management Portal

Complete PHP + MySQL + Bootstrap CRUD project.

## Features
- Create, read, update, and delete students
- Profile photo upload
- Active / Inactive status
- Default Active filter
- Multi-field search: name, email, branch, course
- Branch, course, status, and CGPA range filters
- Total students, average CGPA, active/inactive counts
- Students-per-branch aggregate statistics
- Duplicate-email prevention
- Highest-CGPA highlighting
- Prepared statements and server-side validation
- Responsive Bootstrap dashboard

## XAMPP Setup
1. Copy `Student_Management_Portal` to `C:\xampp\htdocs\`.
2. Start Apache and MySQL.
3. Open `http://localhost/phpmyadmin`.
4. Import `database.sql`.
5. Open `http://localhost/Student_Management_Portal/`.

Default database: `student_management`, user `root`, blank password.
