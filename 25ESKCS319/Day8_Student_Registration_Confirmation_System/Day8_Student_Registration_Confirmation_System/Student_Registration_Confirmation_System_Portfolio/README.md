# Student Registration Confirmation System

A complete Bootstrap 5 + PHP assignment project.

## Features

- Bootstrap 5 responsive form
- Fields: Name, Email, CGPA, Branch, College
- PHP POST processing
- Empty-field validation
- Valid email validation
- CGPA validation between 0 and 10
- Name validation without numbers
- `calculateGrade()` function
- Bootstrap color-coded grade badge
- Confirmation welcome card
- Displays all submitted details
- Displays today's date
- Shared `header.php` and `footer.php` using `include`
- Profile photo placeholder
- Font Awesome icons
- Gradient confirmation card
- Print confirmation button

## Grade Logic

- 9.0–10.0 → A+
- 8.0–8.99 → A
- 7.0–7.99 → B+
- 6.0–6.99 → B
- 5.0–5.99 → C
- Below 5.0 → F

## Run with XAMPP

1. Extract the ZIP.
2. Copy the `Student_Registration_Confirmation_System` folder into:

   `C:\xampp\htdocs\`

3. Start Apache in XAMPP.
4. Open:

   `http://localhost/Student_Registration_Confirmation_System/`

Internet access is required for Bootstrap and Font Awesome CDN files.
